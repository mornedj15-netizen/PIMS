# HealthFirst PIMS (Pharmacy Inventory Management System)

A Java desktop application built for the Programming 732 assignment (Richfield Graduate Institute of Technology). Replaces a pharmacy's manual record-keeping with a role-based system for inventory, sales, and reporting.

## Tech Stack
- **GUI:** Java Swing/AWT
- **Database Connectivity:** JDBC
- **Database:** MySQL

## Modules
1. **Authentication** — role-based login (Admin / Cashier)
2. **Cashier** — Point of Sale, billing, stock check (read-only)
3. **Administrator** — medicine, supplier, and user management (CRUD); sales, item-wise, low stock, and expiry reports

## Default Login Credentials
- **Admin:** `admin` / `admin123`
- **Cashier:** `cashier` / `cash123`
